## Tabela `forms`

### Papel

Cadastro central de formularios.

### Colunas atuais

| Coluna | Tipo atual | Obrigatorio | Observacao |
|---|---|---:|---|
| `id` | INTEGER PK AUTOINCREMENT | sim | identificador |
| `slug` | TEXT UNIQUE | sim | rota publica |
| `type` | TEXT | sim | `presenca` ou `escala_organ` |
| `status` | TEXT | sim | `rascunho`, `aberto`, `fechado`, `arquivado` |
| `title` | TEXT | sim | titulo |
| `session_name` | TEXT | nao | nome curto da sessao |
| `description` | TEXT | nao | descricao |
| `date` | TEXT | nao | data operacional |
| `closing` | TEXT | nao | fechamento |
| `closing_text` | TEXT | nao | mensagem de fechamento |
| `total_expected` | INTEGER | sim | total esperado |
| `labels_json` | TEXT | sim | JSON serializado |
| `field_definitions_json` | TEXT | sim | JSON serializado |
| `scale_sections_json` | TEXT | sim | JSON serializado |
| `results_config_json` | TEXT | sim | adicionado por migration |
| `created_at` | TEXT | sim | ISO string |
| `updated_at` | TEXT | sim | ISO string |

### Indices

- `slug` unico
- `idx_forms_status`
- `idx_forms_type`

### Alvo recomendado em Postgres

- `id BIGINT GENERATED BY DEFAULT AS IDENTITY`
- `slug TEXT UNIQUE`
- `labels_json JSONB`
- `field_definitions_json JSONB`
- `scale_sections_json JSONB`
- `results_config_json JSONB`
- datas operacionais preferencialmente em `TIMESTAMPTZ` ou `DATE`, conforme coluna
