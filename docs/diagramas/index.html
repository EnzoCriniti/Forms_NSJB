Arquitetura geral

A interface conversa com a API. A API valida, aplica regra de negócio e grava no PostgreSQL. O SQLite aparece só como origem legada da importação única.

Interface

Frontend

React + Vite. Telas, modais e navegação do usuário.

Backend

Node, rotas, serviços, repositórios e validação.

Banco oficial

PostgreSQL

Fonte única de dados no ambiente Docker.

Legado

SQLite

Usado apenas como snapshot de migração na primeira subida. Depois disso, não participa do fluxo oficial.

Inicialização da stack

A ordem é previsível: Docker sobe a stack, o PostgreSQL fica saudável, o backend inicia, importa o legado se necessário e o frontend entra por último.

Docker Compose Orquestra os três containers principais.
PostgreSQL Fica saudável e pronto para conexão.
Backend Sobe, valida configuração e aplica seed/importação.
Frontend Fica disponível para uso interno e links públicos.
Importação única: se `storage/nsjb-forms.sqlite` existir no build context, o backend importa o snapshot legado uma vez na primeira subida do PostgreSQL.

Fluxo funcional resumido

O usuário entra pela interface, o frontend chama a API, o backend persiste e o banco oficial consolida o estado da aplicação.

Usuário Abre login, lista ou link público.
Frontend Renderiza telas, modais e fluxos de edição.
Backend + PostgreSQL Valida, grava e consolida resultados e administração.
